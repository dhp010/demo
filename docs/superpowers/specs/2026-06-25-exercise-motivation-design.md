# 운동 동기부여 기능 디자인 스펙

**날짜:** 2026-06-25  
**대상 파일:** `fitness_pwa.html`  
**방식:** 기존 앱에 🏠 홈 탭 추가 (홈 대시보드 신설)

---

## 1. 전체 구조

기존 탭 맨 앞에 **🏠 홈** 탭을 추가. 앱 최초 진입 시 홈 탭이 기본 활성화.

```
[ 🏠 홈 ] [ 🏃 유산소 ] [ 💪 웨이트 ] [ 📚 가이드 ] [ 📅 루틴 ] [ 📋 기록 ] [ 📊 통계 ] [ 🍽️ 칼로리 ]
```

### 홈 탭 레이아웃 (위에서 아래)
1. 스트릭 + 레벨 요약 한 줄
2. 이모지 캐릭터 (크게) + 상태 메시지
3. RPG 스탯 3개 (근력 / 지구력 / 활동량)
4. 오늘의 미션 카드 (랜덤 운동 1개)
5. 부위별 랜덤 루틴 생성
6. 도전과제 미리보기 (진행 중 뱃지 2-3개)

---

## 2. 캐릭터 성장 시스템

### XP 계산 (입력한 운동량에 비례)
- **유산소:** 앱이 계산한 소모 칼로리 = XP (100kcal → 100 XP)
- **웨이트:** 무게(kg) × 세트 × 횟수 = 볼륨, 볼륨 10kg당 1 XP
- **출석 보너스:** 운동을 기록한 날 +50 XP
- **오늘의 미션 완료:** +100 XP

### 레벨 테이블 (10단계)

| 레벨 | 누적 XP | 캐릭터 | 칭호 |
|------|--------|--------|------|
| 1 | 0 | 🥚 | 운동 초보 |
| 2 | 500 | 🐣 | 새싹 트레이니 |
| 3 | 1,500 | 🐥 | 꾸준한 입문자 |
| 4 | 3,000 | 🏃 | 달리는 사람 |
| 5 | 6,000 | 💪 | 근육 성장 중 |
| 6 | 12,000 | 🏋️ | 진지한 트레이너 |
| 7 | 20,000 | ⚡ | 운동 전사 |
| 8 | 35,000 | 🔥 | 불꽃 파이터 |
| 9 | 55,000 | 🦅 | 전설의 시작 |
| 10 | 80,000 | 🦸 | 피트니스 레전드 |

### RPG 스탯 3종 (0-100, 100 초과 시 티어 업)
- **근력:** 웨이트 누적 볼륨 기반 (색상: 회색 → 파랑 → 금색)
- **지구력:** 유산소 누적 거리/시간 기반
- **활동량:** 총 운동 기록 일수 기반

---

## 3. 랜덤 운동 뽑기

### 오늘의 미션 (하루 1개)
- 날짜 기반 시드로 고정 → 새로고침해도 동일, 자정에 교체
- 슬롯머신 스타일 뽑기 애니메이션
- 목표 세트/횟수, 난이도(★) 함께 표시
- **완료** 체크 시 +100 XP 지급
- 하루 1회 넘기기 가능 (넘기면 XP 없음)

### 부위별 랜덤 루틴 생성
- 상체 / 하체 / 전신 / 유산소 중 선택
- 3-5개 운동 + 세트/횟수 + 예상 소요 시간 + 예상 칼로리 출력
- [다시 뽑기] 버튼으로 재생성 가능
- 운동 풀(pool)은 기존 `exercise_guide` 데이터 활용

---

## 4. 도전과제 시스템

### 누적 달성 뱃지

| 카테고리 | 동 | 은 | 금 |
|---------|----|----|-----|
| 달리기 누적 | 10km | 50km | 100km |
| 웨이트 볼륨 | 1톤 | 10톤 | 100톤 |
| 소모 칼로리 | 1만 kcal | 5만 kcal | 10만 kcal |
| 운동 횟수 | 10회 | 50회 | 100회 |

### 연속 스트릭 보상

| 스트릭 | XP 보상 | 추가 보상 |
|--------|---------|---------|
| 3일 🔥 | +200 XP | — |
| 7일 🔥🔥 | +500 XP | 뱃지 |
| 14일 ⚡ | +1,000 XP | 뱃지 |
| 30일 👑 | +3,000 XP | 특별 칭호 |
| 100일 🦸 | +10,000 XP | 레전드 칭호 |

- 뱃지/스트릭 달성 시 팝업 애니메이션 + 축하 메시지

---

## 5. 데이터 구조 (localStorage)

기존 운동 기록 데이터를 읽어서 XP/스탯을 계산. 별도 저장 키:

```js
fitnessMotivation: {
  totalXP: number,
  level: number,
  stats: { strength: number, endurance: number, activity: number },
  streak: { current: number, best: number, lastDate: string },
  achievements: { [badgeId]: { earned: boolean, earnedAt: string } },
  todayMission: { date: string, exerciseId: string, completed: boolean, skipped: boolean },
  lastCalculatedDate: string  // 재계산 방지용
}
```

## 6. 구현 범위 요약

| 기능 | 위치 | 우선순위 |
|------|------|---------|
| 홈 탭 추가 | 탭 네비게이션 맨 앞 | 필수 |
| 캐릭터 + 레벨 표시 | 홈 탭 상단 | 필수 |
| RPG 스탯 바 | 홈 탭 | 필수 |
| XP 계산 엔진 | 기존 기록 기반 | 필수 |
| 오늘의 미션 뽑기 | 홈 탭 | 필수 |
| 부위별 랜덤 루틴 | 홈 탭 | 필수 |
| 도전과제 뱃지 | 홈 탭 하단 미리보기 | 필수 |
| 뱃지 달성 팝업 | 전역 | 필수 |
